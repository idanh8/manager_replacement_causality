# Do Midseason Manager Replacements Improve Football Results?

An observational causal-inference study of Premier League managerial changes between 2015 and 2023.

I assembled fixture and manager-change data, reconstructed evolving league standings, and engineered performance windows around replacement events. The analysis compares causal estimators and examines how conclusions depend on modelling assumptions and potential confounding.

The results are inconclusive and estimator-dependent; a change in performance after replacement does not by itself establish a causal effect.
